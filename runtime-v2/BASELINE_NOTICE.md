# Runtime V2 Engineering Baseline

This tree is a development baseline copied from the released PV-PP Runtime v0.70 source package on 2026-09-15.

- v0.70 remains frozen and released; this copy is not v0.70 and must never be represented as a patch to the release.
- No Version 2 framework modifications have yet been applied in this baseline snapshot.
- Purpose: preserve the full engineering depth of v0.70 while the successor-runtime delta is applied deliberately and audited feature-by-feature.
- The successor runtime will receive its own version/build identity only after the first controlled implementation tranche is complete and verified.
